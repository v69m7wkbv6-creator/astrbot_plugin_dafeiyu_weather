# 大肥鱼天气

给 QQ 聊天机器人用的**自然语言天气插件**：不用记指令、不用每次带城市。第一次问天气时，她会用自己的人设口吻问一句你在哪；你回答一次，她就记住，之后随口问就行。

天气数据来自三个免费公益接口，一个没响应会自动换下一个，最后再交给她用平时的语气说出来，不是冷冰冰的字段播报。

```text
你：今天天气怎么样
她：你在哪个城市呀
她：说个城市名给我，以后我就记着啦

你：临沂
她：记住啦，你在临沂
她：现在晴 12℃，今天 7~18℃
她：早晚有点凉，出门加件外套

你：那明天呢
她：临沂明天多云转阴 11~19℃
她：应该不下雨，不带伞也行

你：我出门了
她：外面 12℃，有点风，外套穿上
```

> 插件本身不带人设。它读取 AstrBot 当前会话的人格提示词来润色，所以换成你自己的角色也能用。

## 二、安装

**方式 A：后台上传（推荐）**

1. 打开 AstrBot 后台 →「插件」→「安装插件」
2. 选「上传文件」，选中 `astrbot_plugin_dafeiyu_weather.zip`
3. 装好后在插件列表里启用「大肥鱼天气」

**方式 B：手动放目录**

把压缩包里的 `astrbot_plugin_dafeiyu_weather` 文件夹整个放到：

```text
<AstrBot 目录>/data/plugins/astrbot_plugin_dafeiyu_weather/
```

然后重启 AstrBot，或在后台点「重载插件」。

> 如果之前装过别的天气插件（比如 `astrbot_plugin_weather`、`astrbot_plugin_qq_weather`），建议先停用，避免两个插件抢着回同一条消息，或者抢同一个 `get_weather` 工具名。

## 三、第一次使用

1. 用**主人 QQ**（AstrBot 管理员）或白名单里的 QQ，私聊机器人发一句：
   ```text
   今天天气怎么样
   ```
2. 她会问你在哪个城市。直接回城市名，比如 `临沂`、`杭州`、`海淀`，也可以说 `我在临沂`、`临沂市`。
3. 她确认记住后，会顺带把当地天气说一遍。之后再问天气就不用说城市了。

群里也能用，但默认要 **@ 她**（避免她看到“天气”两个字就插话）。群里第一次同样会问一次城市，绑定跟着 QQ 走，不跟群走。

## 四、日常说法

不用固定句式，下面这些都能识别：

| 说法 | 效果 |
| --- | --- |
| 今天天气怎么样 | 查绑定地区的实况 + 今日 |
| 明天会下雨吗 | 重点说明天和降水 |
| 那明天呢 / 会下吗 / 周末呢 | 追问，沿用上次的城市，只换范围 |
| 外面冷不冷 / 用不用穿外套 | 重点说温度和穿衣 |
| 需要带伞吗 | 重点说降雨和带伞 |
| 几点开始下雨 / 雨什么时候停 | 小时级降水（Open-Meteo，国内精度一般） |
| 空气质量怎么样 / 有雾霾吗 | 带 AQI |
| 晒不晒 / 要防晒吗 | 带紫外线和生活指数 |
| 我出门了 / 去上班了 | 出门场景，不顺口问天气 |
| 杭州天气 | 临时按杭州查（不改变绑定） |
| 以后查杭州 / 改到杭州 / 我在杭州 | 把绑定改成杭州 |
| 记住老家是临沂 | 加一个别名，之后「老家天气」查临沂 |
| 老家天气 / 公司天气 | 按别名查 |
| （直接发 QQ 位置） | 自动解析城市并绑定 |
| 有气象预警吗 | 中国天气网有预警时顺口提醒 |

认不出来的说法（比如只发一句“好冷”），不会触发插件，留给正常聊天。

## 五、指令（可选）

自然语言已经够用，指令是给习惯打命令的人留的后门：

| 指令 | 作用 |
| --- | --- |
| `/天气` | 用绑定地区查一次；没绑定会先问城市 |
| `/天气 杭州` | 按杭州查一次；没绑定会顺手绑定 |
| `/天气绑定 杭州` | 把地区改成杭州 |
| `/天气解绑` | 忘掉你的地区，下次重新问 |

## 六、配置说明

后台 →「插件」→「大肥鱼天气」→「配置」。所有开关都在这里，下面列关键项。

### 6.1 谁能用

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 白名单 QQ | 空 | 除主人外，还额外允许哪些 QQ 用。一行一个 |
| 私聊所有人都能用 | 开 | 私聊能跟她说话的人都能查（一般由 AstrBot 白名单把关）；关掉后只允许主人和白名单 |
| 群里必须 @ 她才响应 | 开 | 建议保持开启 |
| 第一次问一次城市 | 开 | 关掉就直接用“默认城市” |
| 等她回答城市的时限 | 10 分钟 | 超时没回答，下次重新问 |
| 默认城市 | 空 | 填了以后，没绑定的人直接按这里查 |

「主人」指 AstrBot 主配置里 `admins_id` 里的 QQ 号，插件直接复用。

### 6.2 天气源

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 尝试顺序 | 中国天气网 → Open-Meteo → wttr.in | 越靠前越优先，删掉就不再调用 |
| 单次请求超时 | 6 秒 | 超时判失败，换下一个 |
| 失败重试次数 | 1 | 同一源先重试，再切换 |
| 失败后冷却 | 300 秒 | 刚失败的源这段时间直接跳过 |
| 天气缓存 | 600 秒 | 同城市短时间重复问不重复请求 |

### 6.3 回复

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 回复方式 | 人格润色 | 改成「固定模板」就不花模型 token，但语气平 |
| 使用当前人格 | 开 | 关掉用通用简短口吻 |
| 回复字数上限 | 200 | 人设是短句的可以调成 120～160 |
| 预报天数 | 3 | 给模型参考未来几天 |
| 附加要求 | 空 | 比如“每次都要提醒带伞” |
| 润色超时 | 25 秒 | 超时直接用模板兜底 |

### 6.4 小功能

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 启用 /天气 指令 | 开 | 关掉只保留自然语言 |
| 带上气象预警 | 开 | 有预警时让模型提一句 |
| 带上空气质量 | 开 | 多一次空气质量请求，失败不影响天气 |
| 融入生活指数 | 开 | 穿衣、紫外线、晾晒等挑一两条 |
| 问城市也用人设口吻 | 开 | 关掉省一次模型调用 |
| 接得住追问 | 开 | 「那明天呢」「会下吗」 |
| 追问有效期 | 10 分钟 | 超过就当作新对话 |
| 出门场景提醒 | 开 | 「我出门了」时顺口提醒 |
| 天气影响语气 | 开 | 下雨懒、晴天活泼 |
| 和上次查询对比 | 开 | 「比上次冷了 4 度」 |
| 失败时也用人设口吻 | 开 | 不显示干巴巴的报错 |
| 猜错别字 / 同音字 | 开 | 查不到时让模型猜一次并确认 |
| 支持 QQ 位置卡片 | 开 | 发位置自动绑定 |
| 多城市别名 | 开 | 「老家是临沂」 |
| 小时级降水 | 开 | 「几点下雨」 |
| 天气配表情图 | 关 | 见第 9 节 |
| 节气 / 初雪彩蛋 | 关 | 节气当天、第一场雪 |

### 6.5 主动提醒

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 开启主动提醒 | 关 | 只有遇到预警/大雨/雪/明显降温/高温/严寒/空气很差才发，不是每天固定骚扰 |
| 检查时间（cron） | `0 8 * * *` | 每天 08:00；也可 `0 8,19 * * *` 早晚各查一次（每人每天仍只发一条） |
| 时区 | 空 | 留空跟随 AstrBot |
| 降温提醒阈值 | 6℃ | 比上次记录冷这么多度时提醒 |
| 夜间静音开始 | 22 点 | 这个点之后不发 |
| 夜间静音结束 | 8 点 | 这个点之前不发 |

主动提醒用的是 **AstrBot 自带的定时任务**（`cron_manager`），插件只负责生成提醒内容；如果当前 AstrBot 没有定时任务管理器，会自动跳过并在日志里说明。

## 七、天气源与城市兜底

| 源 | 需要 key | 特点 |
| --- | --- | --- |
| 中国天气网（weather.com.cn） | 不需要 | 国内城市最准，带空气质量、生活指数、气象预警 |
| Open-Meteo | 不需要 | 全球通用，带体感温度、小时级降水，国外城市也能查 |
| wttr.in | 不需要 | 最后的兜底，覆盖广，中文描述偶尔不完整 |

一次查询的流程：

1. 把用户说的地名解析成「城市代码 + 经纬度」
2. **省 / 市 / 区县兜底**：`山东省临沂市兰山区`、`临沂市兰山区`、`浙江杭州`、`杭州余杭区`、`上海浦东新区` 都能自动拆成「省 + 市 + 区」；能拆出区县且天气源有对应区县代码时优先按区县查（如 `兰山区`、`余杭区`），否则落到城市（如 `杭州`）；只说了省（比如“山东省”）会重新问城市
3. **重名城市按省校正**：`辽宁省朝阳市` 会优先取辽宁朝阳，不会落到北京朝阳
4. 按配置顺序逐个尝试天气源；某个源超时/报错/返回异常，就记一次失败并换下一个
5. 失败过的源在冷却期内直接跳过，不会每次都卡在坏源上
6. 拿到的数据统一成同一套结构，再交给人格润色

三个源全挂时，她会用自己的口吻说一句“我这边网好像抽风了”，不会编造数据。

## 八、主动提醒怎么用

1. 先在配置里打开「开启主动提醒」
2. 确认自己的 QQ 已经绑定过城市（私聊问一次天气即可）
3. 默认每天 08:00 检查一次；遇到下面任一情况才私聊你：
   - 气象预警
   - 大雨 / 暴雨 / 雪
   - 比上次记录降温超过阈值（默认 6℃）
   - 高温 ≥ 35℃、严寒 ≤ -5℃
   - AQI ≥ 200
4. 每人每天最多一条；夜间静音时段不发

> 提醒会发到当初绑定时的私聊会话（`umo`）。如果是在群里绑定的，插件会尝试发到 `平台:FriendMessage:QQ号`。

## 九、天气配表情（可选）

默认关闭。开启后，插件会按天气类型去表情目录找图：

```text
data/plugin_data/astrbot_plugin_dafeiyu_weather/memes/
├── rain.png      # 下雨
├── snow.png      # 下雪
├── sunny.png     # 晴
├── cloudy.png    # 阴/多云
├── hot.png       # ≥32℃
├── cold.png      # ≤0℃
└── default.png   # 兜底
```

支持 `.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`。目录可以在配置里改成绝对路径。

> 如果你更想用现有表情包插件的图，保持这个开关关闭即可，两边不会重复配图。

## 十、可视化面板

后台 →「插件」→「大肥鱼天气」→「页面」。面板包括：

- **数据源健康**：每个源当前是正常 / 冷却中 / 失败，上次成功时间、错误原因、冷却剩余秒数
- **绑定列表**：谁绑了哪个城市、什么时候绑的，可以单个删除，也可以手动帮别人改
- **运行状态**：查询次数、缓存命中、自动切换次数、缓存条目
- **调试查询**：输入城市，直接看解析到的地区、拿到的实时数据、模板预览和将要发给模型的提示词（不花 token）

## 十一、常见问题

**她回两遍天气？**
大概率是还装着别的天气插件（两个插件都注册了 `get_weather` 工具，也都在抢同一条消息）。到插件列表停用旧的天气插件即可。

**她一直问城市，回答了还是问？**
- 确认你的 QQ 在 AstrBot 管理员列表或本插件白名单里
- 回答要像地名，比如 `临沂`、`我在临沂`、`杭州余杭`；说“在上班”这种她认不出来
- 也可以在面板里手动给自己加一条绑定

**她说「没找到某某地方」？**
换个写法试试：`临沂`、`临沂市`、`杭州`；特别小的地名可以带上区县，比如 `杭州余杭`。如果怀疑打错字，回一句「是/对」就能确认她猜的城市。

**追问没生效？**
追问只在「上一次查询后 10 分钟内」有效；超过时间就当作新对话。可以在配置里调「追问有效期」。

**主动提醒没收到？**
- 确认「开启主动提醒」开了
- 确认绑定过城市
- 当天没有触发条件（不是每天必发）
- 看后台日志有没有「主动提醒已排期」和「已主动提醒」
- 当前 AstrBot 版本需要带 `cron_manager`

**天气数据不准 / 缺项？**
不同源覆盖不同。中国天气网对国内最准；国外城市会自动落到 Open-Meteo。可以在面板看这次实际用的是哪个源。

**三个源都失败？**
先看面板里的错误信息：如果是网络问题，调大「单次请求超时」；如果某个源长期坏，把它从「尝试顺序」里删掉，或调大冷却时间。

**不想花模型 token？**
把「回复方式」改成「固定模板」，天气数据照常查，只是语气不那么像她；追问、出门、小时级、提醒的模板兜底也都在。

**想让她以后查别的城市？**
直接说 `以后查杭州` / `改到杭州`，或者 `/天气绑定 杭州`；临时查别的城市说 `杭州天气` 就行，不会改绑定。

**群里不回复？**
默认要 @ 她；确认消息里 @ 了机器人，或者把「群里必须 @ 她才响应」关掉。

**节气日期准吗？**
节气用常用近似算法，个别年份可能差一天；默认关闭，介意的话别开。

**换人格 / 换角色还能用吗？**
能。插件读的是当前会话的人格提示词，不绑定“大肥鱼”三个字。

## 十二、隐私与费用

- 只会把**城市名 / 经纬度**发给天气接口，不发送 QQ 号、聊天内容
- 绑定关系存在本机 `data/plugin_data/astrbot_plugin_dafeiyu_weather/bindings.json`
- 三个天气源都免费、不需要注册；`BigDataCloud` 只在发位置卡片时用于反查城市
- 「人格润色」会调用一次当前对话模型，按你 DeepSeek 的用量计费；「问城市」也会调用一次（可关）
- 「主动提醒」每条触发才调用一次模型，每人每天最多一条
